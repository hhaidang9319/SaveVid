2. Giữ nguyên mã JavaScript tải video và Worker trong bộ nguồn. Chỉ bổ sung CSS, bài viết, ảnh minh họa và sửa đường dẫn ảnh từ tuyệt đối sang tương đối để mở index.html từ ổ đĩa vẫn hiển thị.

7. Kiểm tra: mở index.html; nhấp các thẻ bài viết; kiểm tra hình và các liên kết quay lại; thử trên điện thoại.
